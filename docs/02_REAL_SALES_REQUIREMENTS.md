# Requirements from sales chat and uploaded Visit Plan files

## Workflow

1. Supervisor sets district, day, route, assign sales staff; admin prepares price list / quotation
2. Existing customers first, then new prospective shops
3. Sales visits shop, captures photos + map pin/GPS, answers 6 questions
4. Data recorded once in CRM; optional export as PDF/summary later
5. Management reviews, follow-up task and performance compare with ERP mirror

## Mandatory Visit fields (preserve original 6)

1. ร้านค้าเดิมหรือใหม่
2. เบอร์โทรร้านค้า
3. แหล่งที่ซื้อ
4. ประเภทสินค้าที่ใช้
5. ข้อมูลและปัญหาของลูกค้า
6. ความคิดเห็นของลูกค้า

Other: original photos storefront/interior/products/competitor, GPS pin, time, sales owner, visit result, follow-up, competitor quotes, associated ERP customer or CRM lead.

## CRM vs Member

CRM is staff-facing, can see assigned customers, visits, route & forecast; Member is customer-facing and should never see CRM internal notes or other customers.

## Roadmap

- V4 POC deliverables: API tables/views for visits, pins, leads, plans, tasks, private photo upload; Vue CRM forms/map.
- Next phase: quotation builder and PDF, customer import reconciliation, report templates, dynamic manager target planner, route direction provider, offline mobile drafts.
- Next phase: Member LINE login and account verified binding; point calculations and redeem.

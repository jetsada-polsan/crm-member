## 1. เปรียบเทียบความแตกต่างระหว่างต้นแบบ (Modern Mockup) กับหน้าจอเดิม

| มิติการออกแบบ | ต้นแบบ `popstar-modern-mockup/index.html` | หน้าจอเดิม (`web/crm/src/App.vue` & `base.css`) | การแก้ไขที่ดำเนินการ |
|---|---|---|---|
| **Typography & Color Tokens** | ฟอนต์ `'Prompt', system-ui, sans-serif` (14px), `--bg:#f5f7fb`, `--surface:#fff`, `--nav:#111b33`, `--muted:#7a879e`, `--border:#e6ebf2`, `--blue:#3167ed`, `--blue-soft:#eaf0ff`, `--ink:#17223b`, `--green:#0aa67a`, `--shadow:0 6px 24px rgba(22,40,85,.045)` | ใช้ `Sarabun` และไม่มีระบบ CSS Variables ของ Modern Mockup | นำเข้าฟอนต์ `Prompt` และกำหนด CSS Variables + Utility Classes ทั้งหมดจากต้นแบบลงใน `web/shared/base.css` |
| **Application Shell & Navigation** | `.app` + Fixed Dark Sidebar `.sidebar` (`248px`, `#111b33`) แบ่ง 3 หมวด (`WORKSPACE`, `FIELD OPERATIONS`, `MANAGEMENT`) รวม 10 เมนู พร้อม `.logo-mark` (`P`), `.sidebar-bottom` + Sticky `.topbar` (`72px`) ที่มี Breadcrumb, ช่องค้นหา `.search` และ `.profile` | ไม่มี Sidebar และไม่มี Topbar ใช้เพียงปุ่มแนวนอน `.tab` เรียงต่อกันใน `.shell` | เปลี่ยนโครงสร้างเป็น `.app` -> `.sidebar` + `.sidebar-shade` + `.main` -> `.topbar` + `.content` ครบทั้ง 10 เมนูตามต้นแบบ 100% |
| **Quick Customer Acquisition** | Slide-over Drawer ด้านขวา (`.drawer` + `.drawer-backdrop`, `width: min(470px, 100vw)`) เปิดได้จากปุ่ม `＋ เพิ่มลูกค้าใหม่` / `＋ เพิ่มร้านค้า` / `＋ เพิ่ม Lead` ทุกหน้า | แยกเป็นแท็บธรรมดาในหน้าหลัก | สร้าง Slide-over `.drawer` ด้านขวาตามต้นแบบ พร้อมเชื่อม API จริง (`/api/crm/leads/quick`, ตรวจร้านซ้ำ `/api/crm/leads/check-duplicate`, ดึงพิกัด GPS และแนบรูปหน้าร้าน) |
| **Dashboard (`view-dashboard`)** | `.kpis` 4 การ์ดพร้อม `.kpi-icon` (`🏪`, `📍`, `🕒`, `📊`) + `.dash-grid` (`1.6fr 1fr`: กราฟ SVG แนวโน้มยอดขาย/ลูกค้าใหม่ + `.activity` กิจกรรมล่าสุด) + `.middle` (`1.4fr 1fr`: ตารางลูกค้าที่ควรติดตาม + แผนที่ลูกค้า) | มีเฉพาะกล่องตัวเลขธรรมดาและตาราง 2 ตาราง | ใช้โครงสร้าง `.kpis`, `.dash-grid` (กราฟ SVG + กิจกรรมล่าสุดจากข้อมูลจริง + สรุปยอดขายก่อน VAT Bplus Standard) และ `.middle` (ตารางลูกค้า + แผนที่จริง `<CustomerMap>`) |
| **Customer Directory (`view-customers`)** | `.head-filter` (ค้นหา + กรองสถานะ/สายขาย + ปุ่มส่งออก/นำเข้า CSV) + ตาราง `.table` พร้อม `.tag` สีตามสถานะ และปุ่ม `ดูข้อมูล` | แยกตาราง Lead กับ ERP ออกจากกันแบบตารางดิบ | รวมไว้ในเมนู `ทะเบียนลูกค้า` พร้อมตัวสลับดู `ทั้งหมด / ลูกค้าใหม่ (Lead) / ลูกค้า ERP (ซื้อจริง)` และแผงดูรายละเอียด/อนุมัติ Lead หรือดูบิลขาย ERP |
| **Lead Pipeline (`view-pipeline`)** | บอร์ด `.kanban` (`repeat(4, 1fr)`) แสดง `.lane` และการ์ด `.lead` พร้อมจุดพื้นที่ `📍`, เบอร์โทร `☎`, `.tag` ประเภทร้าน | เป็นตารางรายการธรรมดา | แสดงบอร์ด `.kanban` ตามต้นแบบ พร้อมเปลี่ยนสถานะ Pipeline และคลิกเปิดรายละเอียด/อนุมัติร้านค้าได้จริง |
| **Field Visits (`view-visits`)** | โครงสร้าง `.split` (`2fr 1fr`): ซ้ายคือ `แบบฟอร์มเข้าพบลูกค้า` (`.form` 2 คอลัมน์), ขวาคือ `รายการเข้าพบล่าสุด` (`.minirow`) | แยกฟอร์มกับประวัติคนละแท็บ | ใช้โครงสร้าง `.split` (`2fr 1fr`) ตามต้นแบบ เชื่อม API บันทึกการเข้าพบ 6 ข้อ + GPS + รูปถ่ายหน้าร้าน และแสดงรายการเข้าพบล่าสุดด้านขวา |
| **ERP Sync Monitor (`view-sync`)** | `.kpis` 4 การ์ด (`Local Bridge`, `SQL Server`, `ERP Mirror`, `Sync ล่าสุด`) + ตาราง `Sync History` | การ์ด 3 ช่องแบบเก่า | ใช้ `.kpis` 4 การ์ดตามต้นแบบ พร้อมปุ่มสั่งทดสอบ Connection, ดึงตัวอย่าง 10 รายการ (ลูกค้า/สินค้า/บิลขาย), ปุ่ม Sync จริง และตาราง `Sync History` + `Error Logs` |
| **Responsive Breakpoints** | `@media(max-width:1200px)`, `@media(max-width:800px)` (ซ่อน Sidebar + ปุ่ม `☰`), `@media(max-width:520px)` | มีเฉพาะ `@media(max-width:900px)` | ใช้ Responsive Breakpoints ทั้ง 3 ระดับ (`1200px`, `800px`, `520px`) ตรงตามต้นแบบ |
